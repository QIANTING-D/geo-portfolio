数据说明与方法

· 本看板的品牌、问题均真实可核验（安克 为 300866.SZ / 00668.HK 上市企业）。
· 当前为 真实大模型 API（DeepSeek / 豆包(火山方舟)）。切换为真实大模型引用数据：在 config.json 的 "engines" 中保留目标引擎、于 "keys" 填入对应 API key，运行 python run_all.py 即得到各家引擎各自的真实引用结果。
· 无 key 也可得真实数据：mode 改为 "websignal" 通过 DuckDuckGo 实时抓取，复现即可。
· Tableau 用户：用 output/geo_visibility.csv（明细）、geo_by_engine.csv（分引擎宽表）、geo_competitors.csv（竞品）、geo_sources.csv（来源）连接，或按 output/schema.sql 建表后导入 SQLite。
